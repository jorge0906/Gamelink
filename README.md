# 🎮 GameLink

![Licencia](https://img.shields.io/badge/licencia-MIT-blue.svg)

**GameLink** es una plataforma diseñada para conectar a jugadores, facilitar la búsqueda de compañeros de partida, organizar eventos y compartir la pasión por los videojuegos en una comunidad unificada.

## 🚀 Características Principales

* **Búsqueda de jugadores:** Conecta con otros usuarios según tus videojuegos o plataformas favoritas.
* **Gestión de perfiles:** Personaliza tu perfil de jugador y añade tus redes sociales o gamertags.
* **Comunidades y salas:** Espacios orientados a la interacción y organización de partidas colectivas.
* **Interfaz intuitiva:** Navegación pensada para el acceso rápido a todas las funcionalidades clave.

---

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript
* **Control de versiones:** Git & GitHub
